# Dennis Tech Master Course

Welcome to my 60-week technology learning journey.

## Goal
Build practical, demonstrable skills through free learning resources and hands-on projects, then use the portfolio to support entry-level opportunities and freelance work.

## Learning approach
- Start with fundamentals and learn by doing.
- Study consistently and record progress.
- Build small projects before moving to larger ones.
- Document what each project does, how to run it, and what I learned.
- Prioritize free preparation; paid exams are not part of the current budget.

## Portfolio areas
- Digital skills and productivity
- Programming and web development
- Data analysis and visualization
- AI tools and responsible AI applications
- Automation and personal productivity systems
- Practical projects for learning and small-business use

## Progress
The course is planned for 60 weeks across 86 units. Projects and progress notes will be added as they are completed.

## Project documentation template
For each project, record:
1. Problem and intended users
2. Tools and technologies
3. Features
4. Setup and usage instructions
5. Screenshots or demo link (when available)
6. What I learned and next improvements

## Privacy
Do not commit passwords, API keys, access tokens, private documents, or personal financial information. Keep secrets in environment variables and use sample data in public demos.
